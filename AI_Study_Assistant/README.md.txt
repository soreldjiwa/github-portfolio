
# AI Study Assistant

## COSC 4272 – Senior Seminar

**Student:** Brice Nyindie Djiwa

## Project Overview

The AI Study Assistant is a Python desktop application
designed to help students understand computer science
concepts through artificial intelligence.

The application allows users to ask questions about
programming, computer networks, databases, cybersecurity,
and artificial intelligence.

It uses the Llama 3.2 language model through Ollama
to generate explanations and examples.

## Technologies Used

- Python 3
- Tkinter (Graphical User Interface)
- Ollama
- Llama 3.2
- Python threading

## Features

- Interactive desktop interface
- AI-generated answers
- Support for computer science questions
- Conversation display
- Clear Chat button
- Thinking indicator while processing
- Background processing to keep the interface responsive

## How to Run the Application

1. Install Python 3.
2. Install Ollama from https://ollama.com.
3. Download the Llama 3.2 model:

   ollama pull llama3.2:3b

4. Install the Python Ollama package:

   pip install ollama

5. Download ai_study_assistant.py.
6. Make sure Ollama is running.
7. Run the application:

   python ai_study_assistant.py

## Example Questions

- What is cybersecurity?
- Explain TCP and UDP.
- What is Python programming?
- What is artificial intelligence?
- What is SQL?
