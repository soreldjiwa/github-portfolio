
# TCP NewReno vs. Linux Reno

## Project Overview

This project compares TCP NewReno and Linux Reno congestion control algorithms using the ns-3 network simulator.

The purpose of the project is to examine how these TCP algorithms behave under different network conditions and evaluate their performance.

## Course Information

Course: CPSC 4317 - Computer Networks

Project Type: Academic Course Project

## Technologies Used

- C++
- ns-3 Network Simulator
- Ubuntu Linux
- Python for graph generation and analysis

## Project Objectives

1. Configure a network topology using ns-3.
2. Simulate TCP NewReno and Linux Reno.
3. Measure network throughput.
4. Analyze congestion window behavior.
5. Examine packet loss.
6. Compare performance under different network conditions.

## Network Simulation

The simulation uses four network nodes connected through access links and a bottleneck link.

The project examines TCP performance under different network configurations, including changes in bandwidth and delay.

## Project Results

The simulation results were analyzed using throughput measurements, congestion window graphs, and packet loss statistics.

Comparison graphs help illustrate the behavior of the two TCP congestion control algorithms.
