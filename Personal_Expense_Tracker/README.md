
# Personal Expense Tracker

## Project Overview
The Personal Expense Tracker is a desktop application
developed using Python and Tkinter.

This project helps users manage their finances by
recording income and expenses, organizing transactions,
and calculating their remaining balance.

## Features
- Add income and expense transactions
- Categorize financial transactions
- Automatically calculate total income
- Automatically calculate total expenses
- Display the remaining balance
- Delete selected transactions
- Save transactions to a CSV file
- Reload saved transactions automatically
- User-friendly graphical interface

## Technologies Used
- Python 3
- Tkinter
- CSV
- Visual Studio Code or Python IDLE
- GitHub

## How to Run
1. Install Python 3.
2. Download personal_expense_tracker.py.
3. Open the file using Python IDLE.
4. Press F5 to run the application.
5. Add income and expense transactions.

## Testing
The application was tested using sample transactions:

Income: $3,000.00
Expenses: $250.00
Remaining Balance: $2,750.00

The application successfully saved and reloaded
the transactions.
